# Milestone v0.1.0: Initial Release

**Status:** ✅ SHIPPED 2026-07-26
**Phases:** 1–06.1
**Total Plans:** 18

## Overview

wordingo — Pure Go Word Document Library. MIT-licensed, zero-dependency library for creating styled .docx documents from scratch or from templates. Ships OPC package layer, full style engine (clone + resolve + round-trip), document model, content API, rich content (tables, images, headers/footers, lists, hyperlinks, page setup), template merge engine, edit operations, and text extraction + GFM markdown conversion.

## Phases

### Phase 1: Foundation

**Goal**: Library opens any .docx as an OPC package, models essential WML types, and generates a blank .docx Word opens without repair
**Depends on**: Nothing
**Plans**: 3 plans

Plans:

- [x] 01-01: opc package — ZIP I/O, content types, relationship graph, canonical entry ordering, safety limits
- [x] 01-02: xmlutil namespace registry + wml essential types (~60 structs) with round-trip tests
- [x] 01-03: Blank document generator — default styles, theme, fontTable, settings, sectPr; Word-open gate

**Details:**

- Sentinel error taxonomy (ErrInvalidPackage, ErrUnsafePath, ErrDecompressionLimit, ErrTooManyParts, ErrXMLDepth)
- Module identity github.com/fabiomarini/wordingo (go 1.23)
- Create() produces blank .docx opens in Word without repair

### Phase 2: Style Engine

**Goal**: Given any template .docx, library clones its complete style dependency graph and resolves effective properties through the full inheritance chain
**Depends on**: Phase 1
**Plans**: 4 plans

Plans:

- [x] 02-01: Style resolver — recursive basedOn merger, docDefaults, latentStyles, cycle detection
- [x] 02-02: Theme color + numbering resolution; font table handling
- [x] 02-03: Dependency graph cloner (byte pass-through of 5 style parts; STYLE-CLONE-01)
- [x] 02-04: Corpus validation — resolver/theme/numbering effective-props validation over cloned packages; Heading2 chain canonical case (STYLE-CLONE-02)

**Details:**

### Phase 3: Document Model

**Goal**: Library opens, reads, and saves existing documents with zero unintended diffs; creates documents from templates (blank or pre-populated)
**Depends on**: Phase 2

Plans:

**Details:**
