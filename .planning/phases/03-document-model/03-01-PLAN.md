## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | OpenReader body XML decode | low | accept | xmlutil.NewSafeDecoder (inherited from Phase 1) limits entity expansion to 10K expansions. Malformed XML surfaces as decode error, never silent corruption. |
| T-03-02 | Information Disclosure | Open(path) — path string | low | accept | OS-level file open handles path traversal. opc.Open additionally validates ZIP entry names via validatePartName. No new path-handling code beyond stdlib os.Open. |
| T-03-03 | Denial of Service | OpenReader via opc.Open | low | accept | Fully inherited from OPC-07 safety limits: MaxParts (4096), MaxPartBytes (128MB), MaxTotalBytes (512MB), MaxCompressionRatio (100:1). No new resource consumption vectors in Phase 3 orchestration. |
| T-03-SC | Tampering | Package installs | low | accept | Zero new external dependencies in this phase. Only Go stdlib + internal packages. |
</threat_model>
