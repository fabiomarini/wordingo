    Implement four functions:

    1a. `FromTemplate(path string) (*Document, error)`:
        - Open file via os.Open, f.Stat(), defer close.
        - Delegate to FromTemplateReader(f, fi.Size()).
        - Error wrapping: `fmt.Errorf("wordingo: from template %s: %w", path, err)`.

    1b. `FromTemplateReader(r io.ReaderAt, size int64) (*Document, error)`:
        - opc.Open(r, size) — source package with OPC-07 safety.
        - dst := newBlankPackage() — fresh target.
        - style.CloneStyles(src, dst) — byte-copies 5 style parts (styles, numbering, fontTable, theme, settings) per D-09/D-06.
        - dst.MarkModified("word/document.xml", buildEmptyBodyXML()) — replaces body with empty version (CREATE-03, Pitfall 3: replace entirely, never modify in-place).
        - parseDocument(dst) to build *wml.CT_Document for Document.doc field.
        - Return `&Document{pkg: dst, doc: doc}, nil`.
        - NEVER call MarkModified on style parts here (D-06). CloneStyles already handles style part byte-copy via MarkModified — but that's the dedicated clone path, not accidental.

    1c. `OpenTemplate(path string) (*Document, error)`:
        - Same pattern as FromTemplate: open file, defer to OpenTemplateReader.

    1d. `OpenTemplateReader(r io.ReaderAt, size int64) (*Document, error)`:
        - opc.Open(src) source package.
        - dst := newBlankPackage().
        - style.CloneStyles(src, dst).
        - **Body preservation (CREATE-04):** Read source word/document.xml via Part.Open, unmarshal into CT_Document. Copy the Body content (P and Tbl slices) but create a fresh CT_SectPr with default values — do NOT copy source sectPr (Pitfall 4: header/footer rIds would dangle).
          Algorithm:
          - Read source part -> xmlutil.NewSafeDecoder -> xml.Unmarshal into *wml.CT_Document (srcDoc).
          - Build fresh empty body XML via buildEmptyBodyXML().
          - Unmarshal the empty body to get a fresh CT_Document with clean sectPr.
          - Copy srcDoc.Body.P and srcDoc.Body.Tbl into the fresh body.
          - Re-encode the merged CT_Document via xmlutil.NewEncoder.
          - dst.MarkModified("word/document.xml", encodedBytes).
        - Alternative simpler approach (preferred): decode source body, re-encode keeping P+Tbl only with fresh sectPr:
          ```go
          srcPart := src.Parts["word/document.xml"]
          rc, _ := srcPart.Open()
          var srcDoc wml.CT_Document
          xml.NewDecoder(xmlutil.NewSafeDecoder(rc)).Decode(&srcDoc)
          rc.Close()

          // Build fresh doc with source body content but fresh sectPr
          freshDoc := &wml.CT_Document{
              Body: &wml.CT_Body{
                  P:      srcDoc.Body.P,
                  Tbl:    srcDoc.Body.Tbl,
                  SectPr: defaultSectPr(),  // Letter, 1in margins, no HdrFtrRef
              },
          }
          // Encode and MarkModified
          ```
        - parseDocument(dst) for Document.doc field.
        - Return `&Document{pkg: dst, doc: doc}, nil`.

    Add buildEmptyBodyXML() to create.go:

    2a. Add function `buildEmptyBodyXML() []byte`:
        - Creates CT_Document with CT_Body containing only CT_SectPr (no paragraphs, no tables).

        - Encodes with xmlutil.NewEncoder (same pattern as buildDocumentXML).
        - Returns serialized bytes.

    2b. Add helper `defaultSectPr() *wml.CT_SectPr` — returns CT_SectPr with Letter size + 1in margins + no HdrFtrRef/FtrRef. Used by buildEmptyBodyXML and OpenTemplateReader.

    2c. Add `ptrInt64(v int64) *int64` helper — many wml types need *int64. Currently `strPtr` exists for *string. Add alongside.

    Add `(*Document).Doc() *wml.CT_Document` method to Document (in template.go or wordingo.go):
    - Escape hatch for internal use by template functions. Not strictly required on public API per D-02, but useful for OpenTemplate body merging. Place in template.go as unexported helper.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Template source file → Document | Untrusted .docx file supplied by user enters library via FromTemplate/OpenTemplate |
| Template bytes → opc.Open | Template ZIP is parsed by OPC layer with OPC-07 safety limits before any CloneStyles work |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | CloneStyles reads source parts from untrusted template | low | accept | CloneStyles reads via opc.Part.Open which enforces OPC-07 size caps (MaxPartBytes 128MB). Malformed source XML is re-emitted byte-identical (D-09 raw pass-through). No decode/execute of source XML — style XML validity is irrelevant at clone time. |
| T-03-05 | Information Disclosure | FromTemplate/OpenTemplate path or reader — file access | low | accept | OS-level file open enforces permissions. io.ReaderAt from untrusted source goes through opc.Open OPC-07 safety limits. No network access. |
| T-03-06 | Denial of Service | Large template with many style parts | low | accept | OPC-07 MaxParts (4096) limits total entries. MaxPartBytes (128MB) limits individual style part decompressed size. CloneStyles atomic precondition scan fails fast on non-empty target. |
| T-03-SC | Tampering | Package installs | low | accept | Zero new external dependencies. Go stdlib + internal packages only. |
</threat_model>
