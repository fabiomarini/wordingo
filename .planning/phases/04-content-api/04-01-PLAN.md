<objective>
Add paragraph/run builder API with inline and paragraph formatting to the wordingo package.

**Purpose:** Users can create documents programmatically with paragraphs, runs, bold/italic/underline/font/size/color/highlight formatting, plus paragraph alignment/spacing/indentation. All setters return `*T` for builder chaining. Errors deferred to Warnings() at Save time.

</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | SetColor/SetSize validation | low | mitigate | validHexColor rejects non-hex chars; Size validated >= 0. Values stored in typed struct fields — no raw XML injection (ASVS V5). |
| T-04-02 | Tampering | Body XML re-encode via serializeBody | low | accept | CT_Document is built from typed WML structs via xmlutil.NewEncoder (tested in Phase 1). No user-controlled XML fragments reach the encoder. Accept minimal risk. |
| T-04-03 | Denial of Service | serializeBody on huge document | low | accept | Dirty flag ensures one re-encode per Save. Documents are bounded by in-memory construction (user controls input size). No external input amplification. |
| T-04-04 | Information Disclosure | Warnings() leak of document internals | low | accept | Warnings contain validation messages only (e.g., "invalid color"). No sensitive content. Matching Go stdlib convention. |
| T-04-SC | Tampering | Package supply chain | high | mitigate | Zero external deps — Go stdlib only. RESEARCH.md §Package Legitimacy Audit confirms no packages installed. |
