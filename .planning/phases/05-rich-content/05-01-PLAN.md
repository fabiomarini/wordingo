<threat_model>
| Boundary | Description |
|----------|-------------|
| image path -> os.Open | User-supplied path crosses into filesystem via AddImage(path) |
| image bytes -> OPC part | Untrusted image data stored as media part, subject to OPC-07 MaxPartBytes |

| Threat ID | Category | Component | Severity | Disposition | Mitigation |
|-----------|----------|-----------|----------|-------------|------------|
| T-05-01 | Tampering | AddImage(path) — path traversal | medium | mitigate | os.Open validates paths; AddImageBytes is safe API for untrusted names |
| T-05-02 | DoS | EMU overflow (inches * 914400) | low | accept | int64 max / 914400 > 1e13 inches — no realistic input |
| T-05-03 | DoS | Large image decompression bomb | medium | mitigate | OPC-07 MaxPartBytes (128MB) caps decompressed part |
| T-05-04 | Tampering | Table grid vs cell count mismatch | low | accept | Missing cells render empty in Word; warning via Warnings() |
| T-05-SC | Tampering | Package installs | high | mitigate | Zero external deps — Go stdlib only |
</threat_model>
