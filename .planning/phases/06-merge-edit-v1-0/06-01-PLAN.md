Create `merge.go` in package wordingo.

**1. Types:**

Define at package level:
- `ScopedParts` struct with bool fields: `Body`, `Tables`, `Headers`, `Footers` — all default to their zero value (false). Per D-02.
- `MergeOpts` struct with `ScopedParts` field.

**2. Merge method on Document:**

`func (d *Document) Merge(data map[string]string, opts *MergeOpts)` — per D-01.

- If `opts == nil`, create `&MergeOpts{ScopedParts{Body: true, Tables: true, Headers: true, Footers: true}}` — per D-03.
- Initialize `unused` map from `data` keys (all true). Delete key when found.
- Walk in canonical order per RESEARCH §Pattern 1:
  1. Body paragraphs (`d.doc.Body.P`) — if `opts.ScopedParts.Body`
  2. Body tables (`d.doc.Body.Tbl`) — if `opts.ScopedParts.Tables`, recurse Tr.Tc.P
  3. Header parts — if `opts.ScopedParts.Headers`, enumerate via `sectPr.HdrFtrRef` → resolve r:id → read part → decode CT_Hdr → walk P
  4. Footer parts — if `opts.ScopedParts.Footers`, same as headers via `sectPr.FtrRef` → CT_Ftr
- For each paragraph, call `replaceInPara(ct_p, data, unused)`.
- After all walks, for each key still in `unused`, call `d.warn("wordingo: merge key %q not found in document", k)` — per MERGE-03 and D-03.
- Set `d.dirty = true`.

Header/footer walk implementation (per RESEARCH Pitfall 4):
- Read `sectPr.HdrFtrRef` (or `FtrRef`), for each ref:
  - Find rel by `ref.ID` in `d.pkg.Rels["word/document.xml"]`
  - Build part path: `path.Join("word", rel.Target)`
  - Read part bytes, decode as `wml.CT_Hdr` (or `wml.CT_Ftr`)
  - Walk `hdr.P` (or `ftr.P`), call `replaceInPara` on each
  - Re-encode via `xmlutil.NewEncoder` + header.go sync() pattern, call `d.pkg.MarkModified(partPath, buf.Bytes())`
- Use `path` from stdlib (`"path"`) for path.Join.

**3. replaceInPara helper:**

`func replaceInPara(p *wml.CT_P, data map[string]string, unused map[string]bool)`
- Call `replacePlaceholders(p.R, data, unused)` — only scan CT_P.R runs, not CT_P.Hyperlink children (hyperlinks handled separately or left as-is).
- Per RESEARCH Pitfall 1: non-text runs (Br, Tab, Cr, Drawing without T) excluded from joined-text. Only runs with `r.T != nil` participate in char-offset scanning.

**4. replacePlaceholders core function:**

`func replacePlaceholders(runs []*wml.CT_R, data map[string]string, unused map[string]bool)`

Implementation per RESEARCH §Pattern 2:
- Build `joined` string via `strings.Builder`, tracking `runSpans []span{start, end}` for each run where `r.T != nil`.
- Runs with `r.T == nil` get span `{-1, -1}` and are excluded from text scanning — per Pitfall 1.
- Loop via `strings.Index(joined, "{{")` / `strings.Index(joined[start:], "}}")` to find each placeholder.
- Extract `key = text[start+2 : start+end]`.
- Look up `data[key]`; if not found, skip placeholder (continue loop). If found, delete from `unused`.
- Map `[start, start+end+2)` char range back to run indices using `runSpans`.
  - Compute `before` = text in first fragment run before `{{` (i.e., `runSpans[fragmentStart].runText[:placeholderOffset - runSpans[fragmentStart].start]`).
  - Compute `after` = text in last fragment run after `}}` (i.e., `runSpans[fragmentEnd].runText[placeholderEnd - runSpans[fragmentEnd].start:]`).
  - If `fragmentStart == fragmentEnd`: single run — use `strings.Replace(runText, "{{" + key + "}}", value, 1)` on the run text directly.
  - Else (split-run, per D-05): set `runs[fragmentStart].T.Value = before + value + after`. For runs `fragmentStart+1` through `fragmentEnd`, set their `T.Value = ""` (do NOT nil the run or delete it — preserve the CT_R element and its formatting children). Per D-05 first-fragment formatting rule — prefix and suffix text both collect into the first fragment run.
- Continue loop from `placeholderEnd` position in joined text.

**5. replaceInTable helper:**

`func replaceInTable(tbl *wml.CT_Tbl, data map[string]string, unused map[string]bool)`
- For each `tbl.Tr[i].Tc[j].P[k]`, call `replaceInPara(p, data, unused)`.
- Nested tables (CT_Tc.Tbl) not handled per RESEARCH Pitfall 2 — deferred behind v1.

**Import requirements:** `"bytes"`, `"fmt"`, `"path"`, `"strings"`, and the existing `"github.com/fabiomarini/wordingo/internal/opc"`, `"github.com/fabiomarini/wordingo/internal/wml"`, `"github.com/fabiomarini/wordingo/internal/xmlutil"`.
