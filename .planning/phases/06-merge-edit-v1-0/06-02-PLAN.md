**B. Modify `header.go` — ParagraphContainer interface:**

Add the following to `header.go` (per D-07, agent discretion on interface shape):

```go
type ParagraphContainer interface {
    Paragraphs() []*Paragraph
    InsertParagraphAt(idx int, ct *wml.CT_P) *Paragraph
    DeleteParagraphAt(idx int)
}
```

Implement on `*Header`:
- `func (h *Header) Paragraphs() []*Paragraph` — wraps `h.ct.P` into `[]*Paragraph` with doc reference.
- `func (h *Header) InsertParagraphAt(idx int, ct *wml.CT_P) *Paragraph` — splice insert into `h.ct.P` slice at idx, call `h.sync()`, return new Paragraph.
- `func (h *Header) DeleteParagraphAt(idx int)` — splice delete from `h.ct.P` at idx, call `h.sync()`.
- Nil-receiver guard panics on all methods per existing pattern.

Implement on `*Footer`:
- Same three methods mirroring Header implementation but operating on `f.ct.P`.

Import `"github.com/fabiomarini/wordingo/internal/wml"` (already present in header.go).

**C. Modify `wordingo.go` — InsertBefore/After/DeleteParagraph on Document:**

NOTE: The `strings` import is NOT needed in wordingo.go for these methods (they create CT_P with CT_R/CT_Text directly per existing AddParagraph pattern).

Three methods per D-06 (pointer-based, no index parameters):

`func (d *Document) InsertBefore(target *Paragraph, text string) *Paragraph`:
- Nil-guard: if d == nil, panic.
- Guard: if target == nil, call `d.warn("wordingo: InsertBefore: target is nil")` and return nil.
- Create new CT_P with single run containing text (same pattern as AddParagraph L236-239).
- Search `d.doc.Body.P` by pointer identity: `if p == target.ct { found = true; ... }`.
- If found: splice insert before index i (`d.doc.Body.P = append(d.doc.Body.P[:i+1], d.doc.Body.P[i:]...); d.doc.Body.P[i] = ct`).
- If not found in body: try ParagraphContainer via target's doc pointer — PER DISCRETION: delegate by checking if target.doc has a container reference (not needed for v0.1.0 — just warn and return nil). Per D-07, this is reserved for future Header/Footer paragraph editing via the interface.
- Set `d.dirty = true`.
- Return `&Paragraph{ct: ct, doc: d}`.

`func (d *Document) InsertAfter(target *Paragraph, text string) *Paragraph`:
- Same pattern as InsertBefore but splice after index i (`d.doc.Body.P[i+1] = ct`).
- Return new Paragraph.

`func (d *Document) DeleteParagraph(target *Paragraph)`:
- Nil-receiver guard.
- If target == nil: warn and return.
- Search `d.doc.Body.P` by pointer identity.
- If found: splice delete (`d.doc.Body.P = append(d.doc.Body.P[:i], d.doc.Body.P[i+1:]...)`).
- If not found: warn `"wordingo: DeleteParagraph: target paragraph not found in body"` and return (no panic per QUAL-02).
- Set `d.dirty = true`.
