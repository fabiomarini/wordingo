    parser.go — package markdown:
    - Import: bufio, regexp, strings, fmt

    Define exported BlockType int with iota constants:
    - BlockParagraph, BlockHeading, BlockCodeBlock, BlockOrderedList, BlockBulletList, BlockTable

    Define exported Block struct:
    - Type BlockType
    - Level int (heading level 1-6, list nesting level)
    - Content string (inline content for paragraphs/headings/list items)
    - Lines []string (raw lines for code blocks)
    - Cells [][]string (pipe table cells, first row = header)
    - Language string (code block language hint)
    - ListItems []Block (nested list items for list blocks)

    Define exported InlineSpan struct:
    - Text string
    - Bold, Italic, Code bool
    - LinkURL, LinkText string
    - ImageURL, ImageAlt string

    Define package-level regexp.MustCompile variables:
    - headingRe: ^(#+)\s+(.+)$
    - fenceOpenRe: ^```(\w*)$
    - fenceCloseRe: ^```$
    - orderedListRe: ^(\s*)(\d+)\.\s+(.+)$
    - bulletListRe: ^(\s*)[-*+]\s+(.+)$
    - tableRowRe: ^\|(.+)\|$
    - tableSepRe: ^\|[-:| ]+\|?$
    - boldRe: \*\*(.+?)\*\*
    - italicRe: \*(.+?)\*
    - codeSpanRe: `([^`]+)`
    - linkRe: \[([^\]]+)\]\(([^)]+)\)
    - imageRe: !\[([^\]]*)\]\(([^)]+)\)

    Define exported Parse(input string) ([]Block, error):
    - Returns empty slice for empty input, no error
    - Uses bufio.Scanner for line-by-line block parsing
    - Two-pass: first pass identifies blocks, second pass (per block) parses inline content
    - Block parsing state machine tracks: inCodeBlock (bool, with language), listLevel, inTable

    Block parsing rules per GFM subset (D-13):
    - Heading: line matches headingRe → capture group 1 count = level (1-6), group 2 = content → BlockHeading
    - Code fence: fenceOpenRe → set inCodeBlock=true, collect lines until fenceCloseRe → BlockCodeBlock with language hint from opening fence. Content within code block is NOT inline-parsed
    - Table: line matches tableRowRe → collect until blank line or non-matching line. First row = header. Second row must match tableSepRe → column alignment from :--- / :---: / ---: colon positions (agent discretion). Data rows follow. → BlockTable with Cells[][]string
    - Ordered list: orderedListRe → parse indent level (spaces / 2 = level), number, content. Consecutive matching lines → one BlockOrderedList. Different indent = nesting
    - Bullet list: bulletListRe → same pattern as ordered but list marker -/*/+ → BlockBulletList
    - Else: → BlockParagraph (empty content for blank line separators)

    Inline parsing per block (skip for code blocks):
    - For each non-code Block (paragraph, heading, list item), run inline parser
    - Priority order: code spans first, then images, then links, then bold, then italic
    - regexp.FindAllStringSubmatchIndex, process left-to-right, build InlineSpan slice
    - Return []InlineSpan on the Block (add Inlines field to Block struct)

    parser_test.go — package markdown:
    - Table-driven tests for each block type:
      - heading: "# H1" through "###### H6"
      - paragraph: "Hello world"
      - code block: ```go\npackage main\n``` with language detection
      - ordered list: "1. first\n2. second"
      - bullet list: "- item\n- another"
      - pipe table: "| a | b |\n|---|---|\n| 1 | 2 |"
    - Edge cases: empty input, malformed table (missing separator), nested lists, code spans inside paragraphs, bold+italic combined, links with URLs, images
    - Error/edge: very long input, only whitespace, HTML not parsed (should be paragraph)
    - Use t.Fatalf/t.Errorf, no external test framework
  </action>
  <acceptance_criteria>

    - Parse("1. first") returns BlockOrderedList
    - Parse("|a|b|\n|---|---|\n|1|2|") returns BlockTable with Cells {{"a","b"},{"1","2"}}

    - Detect heading: if ct_p.PPr != nil && ct_p.PPr.PStyle != nil && ct_p.PPr.PStyle.Val != nil → check prefix "Heading" + suffix digit 1-6. If match, set headingLevel = digit, emit "#"*level + " " prefix
    - Detect list: if ct_p.PPr != nil && ct_p.PPr.NumPr != nil → read numbering.xml via readOrCreateNumbering(). Lookup numId → abstractNumId → find CT_AbstractNum → find level 0 lvl → numFmt. If numFmt == "bullet", unordered "- "; else ordered "1. " (or use actual ilvl number per agent discretion)

    Inline formatting rules per D-08/D-09:
    - CT_R.RPr.B not nil AND (Val == nil OR *Val == true) → surround with **
    - CT_R.RPr.I not nil AND (Val == nil OR *Val == true) → surround with *
    - CT_R.RPr.Strike not nil AND (Val == nil OR *Val == true) → surround with ~~
    - CT_R.RPr.U → stripped (not in GFM)
    - CT_R.Drawing not nil → resolve image: find relationship in d.pkg.Rels["word/document.xml"] with rId from drawing's blipFill relationship. Read target part bytes. Detect image type from first bytes (PNG: 89 50 4E 47, JPEG: FF D8). Base64 encode. Emit as ![image](data:image/{type};base64,{data}). Per D-09 — only PNG/JPEG from DrawingML anchors supported via image type byte detection
    - CT_Hyperlink → for each child run, collect text. Lookup hyperlink.ID in d.pkg.Rels["word/document.xml"] → relationship.Target. Emit [text](url). Collect all child run text as link text

    Add unexported tableToMarkdown(tbl *wml.CT_Tbl) string:
    - Iterate tbl.Tr[]. For each tr, iterate Tc[]. For each tc, collect paragraph texts.
    - Header row: first tr. Emit GFM pipe table: | cell1 | cell2 | ... |
    - Separator row: | --- | --- | ... | (left-aligned default per agent discretion; check first cell pPr for alignment hint)
    - Data rows: remaining tr
    - Escape cell content: replace \ with \\, replace | with \| using escapePipeCell helper per Pitfall #3
    - Blank cells for missing columns

    Link ToMarkdown walk with same ScopedParts structure as ExtractText:
    - Body: for each CT_P, call paragraphToMarkdown. For each CT_Tbl, call tableToMarkdown
    - Tables: same as ExtractText table iteration but emitting pipe table
    - Headers: readHeaderParts, iterate hdr.P, call paragraphToMarkdown
    - Footers: readFooterParts, iterate ftr.P, call paragraphToMarkdown
    - Join with separator between elements

    Helper functions:
    - escapeMarkdown(s string) string: escape GFM special chars. Replace \ → \\, * → \*, ` → \`, [ → \[
    - escapePipeCell(s string) string: replace \ → \\ then | → \| (per GFM spec §4.10)
    - imageMIMEFromHeader(data []byte) string: check first bytes for PNG (89504E47), JPEG (FFD8), return "image/png" or "image/jpeg". Default "image/png"
