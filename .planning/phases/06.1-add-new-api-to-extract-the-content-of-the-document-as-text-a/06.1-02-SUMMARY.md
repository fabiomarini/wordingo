# Plan 06.1-02: Markdown Import

## Summary

Implemented markdown import functions using the GFM parser from Plan 1 and the existing Document builder API.

### Files Created

- `markdown_import.go` — `CreateFromMarkdown`, `(*Document).ImportMarkdown`, `importBlocks`, `decodeDataURI`

### Key Decisions

- `CreateFromMarkdown` creates a fresh Document via `Create()`, parses markdown, and builds content
- `ImportMarkdown` appends to existing document body, surfaces parse errors as warnings
- Lists use manual paragraph construction with `NumPr` for inline formatting support
- Images from data URIs decoded via `decodeDataURI` and embedded via `AddImageBytes`
- Code blocks use `Consolas` font on each line as separate paragraphs
- `importTable` passes all cells through to `AddTable` (header row + data rows)
- Sets `d.dirty = true` after successful import
