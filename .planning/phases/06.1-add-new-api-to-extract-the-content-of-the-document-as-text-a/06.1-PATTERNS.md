## Shared Patterns

### ScopedParts Walk Pattern (Read-Only)
**Source:** `merge.go` lines 28-78 (write variant)
**Apply to:** `extract.go`, `markdown.go`
**Pattern:**
```go
if opts.ScopedParts.Body {
    for _, p := range d.doc.Body.P { /* process paragraph */ }
}
if opts.ScopedParts.Tables {
    for _, tbl := range d.doc.Body.Tbl {
        for _, tr := range tbl.Tr {
            for _, tc := range tr.Tc {
                for _, p := range tc.P { /* process cell paragraph */ }
            }
        }
    }
}
```

### Read-Only Header/Footer Walk
**Source:** `merge.go` lines 172-214 (write variant)
**Apply to:** `extract.go`, `markdown.go`
**Pattern:** Same decode as walkHeaderParts but SKIP the re-encode + MarkModified block (merge.go lines 200-214). No `d.dirty = true`.

### Nil-Safe Opts with Defaults
**Source:** `merge.go` lines 33-35
**Apply to:** `extract.go`, `markdown.go`
```go
if opts == nil {
    opts = &ExtractOpts{ScopedParts: ScopedParts{Body: true, Tables: true, Headers: true, Footers: true}}
}
```

### Paragraph Text Including Hyperlinks
**Source:** Custom helper per RESEARCH.md §Assumptions A1
**Apply to:** `extract.go`, `markdown.go`
```go
func paragraphText(p *wml.CT_P) string {
    var b strings.Builder
    for _, r := range p.R {
        if r.T != nil { b.WriteString(r.T.Value) }
    }
    for _, hl := range p.Hyperlink {
        for _, r := range hl.R {
            if r.T != nil { b.WriteString(r.T.Value) }
        }
    }
    return b.String()
}
```

### Non-Text Elements Silently Skipped
**Source:** `merge.go` placeholder detection only checks `r.T != nil` (merge.go lines 91-98)
**Apply to:** `extract.go`, `markdown.go`
Run `Br`, `Tab`, `Cr`, `Drawing` fields on `CT_R` (`internal/wml/document.go` lines 84-88) are simply not checked when collecting text.

### Builder Chaining Returns Receiver
**Source:** All builder methods (`paragraph.go`, `run.go`, `list.go`, `table.go`)
**Apply to:** `markdown_import.go` (when creating content)
```go
func (p *Paragraph) SetStyle(name string) *Paragraph { return p }
func (r *Run) SetBold(b bool) *Run { return r }
```

### Numbering Definition Creation for Lists
**Source:** `list.go` lines 195-219
**Apply to:** `markdown_import.go` (when importing ordered/bullet lists)
Pattern: `readOrCreateNumbering()` → `findMaxAbstractNumID`/`findMaxNumID` → build `CT_AbstractNum` + `CT_Num` → `writeNumbering`
